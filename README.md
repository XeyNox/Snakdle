# 🐍 Snakdle

> A snake-themed idle clicker game with gacha pulls, boss fights, and rebirths.

---

## 🎮 Gameplay Loop

1. **Spawn** — You start with your snake immediately, no setup needed.
2. **Earn Stats Currency** — Click on the screen to collect currency, or idle and let it accumulate passively.
3. **Upgrade Your Stats** — Spend your stats currency to grow stronger.
4. **Fight the Boss** — Once you're strong enough, take on the boss. Boss levels scale exponentially.
5. **Earn Pull Currency** — Defeating a boss rewards you with gacha pull currency.
6. **Pull Characters** — Use pull currency in the gacha system to unlock characters and bonuses.
7. **Repeat** — Loop back and get stronger each time.

---

## ✨ Gacha System

- Pull **skins** using currency earned from boss fights.
- Each skin you equip grants **unique power-up bonuses** to your snake.

### Rarities

| Rarity | Description |
|---|---|
| ⬜ Common | Basic skins, easy to obtain |
| 🟩 Uncommon | Slightly better power-ups |
| 🟦 Rare | Solid stat boosts |
| 🟪 Epic | Powerful bonuses |
| 🟨 Legendary | Exceptional power-ups |
| 🔴 FrenchMonster | The rarest tier — ultimate power |

---

## 🔁 Rebirth System

- At any point, you can choose to **Rebirth** — resetting your progress in exchange for permanent bonuses.
- Rebirth bonuses stack across runs, making each loop more powerful than the last.
